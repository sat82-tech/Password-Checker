# 🔒 Password Strength Checker & Generator

A simple and secure Python-based tool designed to check password strength and generate strong, random passwords. Built to improve cybersecurity awareness and practice core Python programming concepts.

## ✨ Features
* **Password Strength Analysis:** Evaluates passwords based on length, uppercase/lowercase letters, numbers, and special characters.
* **Instant Feedback:** Provides a detailed report with constructive feedback on weak or medium passwords.
* **Secure Password Generator:** Automatically generates robust 12-character passwords containing a mix of letters, digits, and symbols.

## 🚀 How to Run
1. Make sure you have Python installed on your system.
2. Download or clone this repository.
3. Run the script using the terminal/command prompt:
   ```bash
